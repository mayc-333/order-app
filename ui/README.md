# COZY 커피 주문 앱 - 프런트엔드

Vite + React (JavaScript) 기반 프런트엔드 개발 환경입니다.

## 기술 스택

- React 19
- Vite 8
- JavaScript (JSX)

## 시작하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행 (http://localhost:5173)
npm run dev

# 프로덕션 빌드
npm run build

# 빌드 결과 미리보기
npm run preview
```

## 폴더 구조

```
ui/
├── public/          # 정적 파일
├── src/
│   ├── assets/      # 이미지 등 리소스
│   ├── App.jsx      # 루트 컴포넌트
│   ├── App.css
│   ├── main.jsx     # 앱 진입점
│   └── index.css    # 전역 스타일
├── index.html
└── vite.config.js
```
